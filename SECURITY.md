# Security reporting

Do not open a public issue containing uploaded material, personal information, tokens, keys or exploit details. Use GitHub's **Report a vulnerability** private reporting facility when it is enabled. The operator must publish and monitor a private security/privacy contact before the student pilot; that contact is not yet supplied.

The anonymous preview is intended for synthetic or non-sensitive material only. Current pilot approval is **HOLD** until the release checklist and independent reviews are complete. Do not treat passing automated checks as certification.

Production changes require a pull request, the Security checks job and an independent reviewer. The maintainer owns weekly dependency-advisory review and a review after every material provider, parsing, hosting or storage change. GitHub/Cloudflare account MFA, member roles and secret access require owner verification.
