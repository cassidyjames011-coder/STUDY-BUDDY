# Deployment runbook
Install with pnpm install --frozen-lockfile --ignore-scripts. Run pnpm check, pnpm audit --audit-level=high and both Wrangler dry-run builds. Commit source and generated assets, then generate manifest against that exact commit. Capture previous isolated staging version and bindings; deploy wrangler.staging.jsonc only after authentication and inventory. Verify immutable version, served hashes and mock-only isolation; perform staging rollback and restore candidate. Record all identifiers. Production requires explicit owner approval; never change production secrets. Frontend AI_GATEWAY must map to the compatible API revision; production ALLOWED_ORIGIN must match the approved hosting origin.
